--------------------------------------------------------------------------------
ARCHITECTURE

Offline: Exportify CSVs -> resolve_previews.py (Deezer track ids by ISRC)
-> build_timeline.py -> data/processed/timeline.json (sorted by Added At).
Runtime: main.js registers every element with the UI Layout Engine (position/size
from lib/ui-engine; Inspector for edits), loads timeline.json; a scrub (wheel /
touch drag / arrow keys / click on the timeline) moves a float position; each
change of floor(position) (the last song added at or before it) re-renders the
song card + timeline, plays that song's preload-pool
clip from a random offset, and re-centers the preload window (wider when
scrubbing fast). After `Handoff Delay` ms of no movement the clip stops and
the Spotify embed plays the real song. clipPlayer asks /api/preview for fresh
clip URLs; nothing about URLs is ever persisted. The app reads dev-panel
values live from the controls' DOM (settings.js) -- there is no second copy of
any setting. The dev panel never depends on the app.
